# RaceDay
RaceDay Event Management System - Planning and Database
## System Overview
RaceDay is a comprehensive event management system designed for organizing and managing running events, marathons, and races. The system allows event organizers to create and manage events, while participants can register, enroll in categories, and track their results.

## System Roles

### 1. Organiser
- Create and manage events
- Add categories to events
- View participant enrolments
- Record race results
- Update event status and details
- Delete or cancel events

### 2. Participant
- Register and manage profile
- View available events
- Enroll in events and categories
- Track personal enrolments
- View personal race results
- Cancel enrolments

4. Run the application

## Database Schema
The database consists of 5 main tables:
- **Users**: Stores user accounts (both organizers and participants)
- **Events**: Contains all race events
- **Categories**: Event categories with entry fees
- **EventEnrolments**: Tracks participant registrations
- **Results**: Stores race results and positions
